## If she's stuck

| Stuck on | Do this |
|---|---|
| A few letter sounds won't stick | Put them on the "practice pile." Two minutes daily of the hunt (#3) or hopscotch (#4) with *only* those letters. Give each one a body action. |
| Knows sounds but can't blend | Ears, not eyes. Go back to Week 2–4 oral games (#6, #8, #11) for two weeks with no letters. Then try continuous blending with stretchy words: *sun, man, fin, mom*. |
| Blends "kuh-a-tuh" and gets lost | Sounds have an "uh" tail. Practice saying t, p, k, d as tiny puffs. Use only stretchy-sound words for a week. |
| Guesses from pictures | Cover the picture. Finger under the first letter: "what sound?" |
| Reads the word, forgets it seconds later | Normal at 4. Reread the same book 3 days running. Speed comes with repetition, not correction. |
| Hates writing | Drop the workbook for 2 weeks. Only playdough, chalk, salt tray, tweezers, cutting. Come back to it with air writing (#39) and wet-dry-try (#28). |
| Reverses letters (b/d, S, N) | Normal until 6–7. Show the right way once, cheerfully. Don't drill. |
| Counts but skips objects | "Touch and count" (#41). Line objects up in a row. Slow it down; move each counted object to a "counted" pile. |
| Recounts instead of saying "how many" | Cardinality is still forming. Keep asking "so how many?" after every count and answer it for her sometimes. It clicks. |
| Bored with everything | Cut to 5-minute blocks. Only games and read-alouds for a week. Let her pick the order. Resistance is almost always "too long," not "too hard." |
