# Printables

- `weekly-plans.pdf` — 13 pages: Weeks 1–12, one page each, plus a blank week. Print, hang up, tick the Mon–Fri boxes.
- `checklists.pdf` — 6 pages to hang: Ayah's Letter Sounds, Words I Can Read, Books I Can Read, Ayah Can Write, Ayah's Math, Our Learning Chart (monthly sticker chart; print 3 copies).

To change the letter groups or activities, edit `build.py` and run `./build.sh` (needs Python 3 and Chromium). The `.html` files are the print sources.
