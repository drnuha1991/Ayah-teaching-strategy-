# Printables

- `all-in-one.pdf` — **everything in one file to print (41 pages):** the complete guide, then the 13 weekly pages, then the 6 checklists.
- `complete-guide.pdf` — the guide only (22 pages): overview, resources, how to teach, 12-week plan, activity bank, progress tracker.
- `weekly-plans.pdf` — 13 pages: Weeks 1–12, one page each, plus a blank week. Hang up, tick the Mon–Fri boxes.
- `checklists.pdf` — 6 pages to hang: Ayah's Letter Sounds, Words I Can Read, Books I Can Read, Ayah Can Write, Ayah's Math, Our Learning Chart (monthly sticker chart; print 3 copies).

To change anything, edit the markdown files (guide) or `build.py` (weekly pages and checklists), then run `./build.sh`
(needs Python 3 with `markdown` and `pypdfium2`, and Chromium). The `.html` files are the print sources.
